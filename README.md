# The Office Suite: downloads

Signed installers for **The Office Suite**: CounterPoint, Exhale, Lookout, Notes-A-Many, Projectile and Turd.

Get the latest from [Releases](../../releases/latest):

- `TheOfficeSuite-Setup-<version>.exe`: double-click to install (Windows 10/11, 64-bit).
- `TheOfficeSuite-<version>.msi`: for deployment tools (`msiexec /i TheOfficeSuite-<version>.msi /qn`).

Installed copies keep themselves up to date from this page. Every file is signed by Schema Networks LLC.
